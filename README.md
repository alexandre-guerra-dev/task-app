# Task App

Uma aplicação clássica de gerenciamento de tarefas.

## Funcionalidades

- Login/Registro de usuário
- Cookie Authentication
- CRUD de tarefas

## Tecnologias

- .NET 8
- Identity
- Entity Framework Core
- SQLite

## Pré-requisitos

- .NET SDK 8
- Git

## Como executar

### Backend

Abra o terminal e execute os seguintes comandos:

```bash
dotnet restore
dotnet run
```
